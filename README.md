# Heartheartart

Discord bot that captures a page, stores a snapshot, and publishes a link card. The Next.js app in `frontend/` reads those cards.

## Install

```bash
python -m pip install .
```

## Run

```bash
heartheartart
```

The bot reads its configuration from the environment. See `docker-compose.yml`.
